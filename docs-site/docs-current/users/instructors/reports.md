Review course activity and export report data.

## Open a report

1. Open **Reports**.
2. Choose the course or report type.
3. Set the date range and filters.
4. Review the learner, enrollment, completion, or grade data.
5. Select **Export** when you need a file for further analysis.

Report availability depends on your role and the modules enabled in the installation.

## Verify

After changing a filter, confirm that the displayed course and date range match the report you intend to use. Open an exported file and check its header and row count.

## Troubleshooting

- **A report is empty:** widen the date range and check the selected course and tenant.
- **A report is unavailable:** ask an administrator to confirm your report permission.
- **The export is incomplete:** wait for the export to finish and download the generated file again.
