Add learners to a course.

## Before you start

You need permission to manage enrollments and a published course. Each learner must have a CMDX account.

## Enroll learners

1. Open **Enrollments** and select **New enrollment**.
2. Choose the course.
3. Select the learner or learners.
4. Choose the enrollment method or group, if your installation provides those options.
5. Review the start and end dates.
6. Select **Enroll**.

For a larger list, use the bulk-enrollment option and follow its validation messages before submitting.

## Verify

Open the course enrollment list. Confirm that each learner appears with the expected status. Ask one learner to open **My Learning** and confirm that the course is available.

## Troubleshooting

- **A learner is not listed:** confirm that the account exists and that you have selected the correct tenant.
- **The course is unavailable:** check the course status, visibility, and enrollment dates.
- **A duplicate is rejected:** review the learner's existing enrollment instead of creating another one.
