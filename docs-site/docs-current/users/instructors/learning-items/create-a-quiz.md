Build a quiz, configure its grading, and place it in a course.

## Create the quiz

1. Open the course builder.
2. Select **Add learning item**, then choose **Quiz**.
3. Enter the title and instructions.
4. Open the quiz editor and add questions.
5. Choose each question type and enter its answers, points, and feedback.
6. Configure attempts, time limits, passing score, and any availability dates.
7. Select **Save**.
8. Place the quiz in the intended section.

Questions that require manual review, such as subjective answers, remain in the grading queue after submission.

## Verify

Preview the quiz as a learner. Check the question order, scoring rules, time limit, and result visibility before publishing the course.

## Troubleshooting

- **A question has no score:** add points or check whether it is an informational question.
- **The quiz cannot be published:** complete the required title, questions, and settings.
- **A result is waiting:** review the attempt in **Grading**.
