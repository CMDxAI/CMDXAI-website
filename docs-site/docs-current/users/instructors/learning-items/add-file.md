Add a PDF or another downloadable file to a course.

## Add the file

1. Open the course builder.
2. Select **Add learning item**, then choose **File**.
3. Enter the item title and description.
4. Choose **Upload file** and select the file.
5. Set the item and completion options.
6. Select **Save**.
7. Place the item in the intended course section.

The file item keeps a version history when you replace the file. Replace the file when the learning item should keep its identity and enrolments.

## Verify

Open the item as a learner. Confirm that the file name and download action are visible and that the completion state updates as expected.

## Troubleshooting

- **The upload fails:** check the file type, size limit, storage configuration, and available space.
- **The item is not visible:** confirm that it is placed in a section and that the course is published.
- **A replacement is not shown:** refresh the item and check its version history.
