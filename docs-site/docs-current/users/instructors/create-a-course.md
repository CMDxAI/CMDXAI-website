Create a course, add learning items, and publish it for learners.

## Before you start

You need an instructor or administrator account with permission to create courses. Prepare a course name, a short name, and the content you want to publish.

## Create the course

1. Open **Courses** and select **New course**.
2. Enter the **Course name**. This is the name learners see.
3. Enter a unique **Short name**.
4. Choose a **Category**.
5. Add a summary or description.
6. Set the course dates and, if needed, the dates when enrollment opens and closes.
7. Select **Save**.

The new course starts as a draft. Open it in the course builder and add sections and learning items.

## Publish the course

1. Review the course details and content.
2. Confirm that learners should be able to see and enroll in the course.
3. Select **Publish course**, then confirm.

Publishing makes the course available according to its enrollment and visibility settings.

## Verify

Open the course as a learner or use a test learner account. Confirm that the course appears, its sections load, and each published item opens.

## Troubleshooting

- **The course cannot be saved:** check the required name, short name, category, and date fields.
- **Learners cannot find it:** confirm that the course is published and visible, and that enrollment is open.
- **An item is missing:** return to the builder and check that the item is placed in a section and saved.
