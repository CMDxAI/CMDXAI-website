Enroll in a course and work through its learning items.

## Open a course

1. Sign in to CMDX.
2. Open **My Learning**.
3. Select a course you are enrolled in.
4. If the course is available for self-enrollment, select **Enroll** and confirm.

## Work through the course

1. Open the first available section.
2. Select an item to start learning.
3. Follow the item instructions.
4. Use **Next** or the item navigation to continue.
5. Return to the course home to see your progress.

Some items have prerequisites or completion rules. Complete the required activity before moving to the next item.

## Verify

Return to **My Learning** and open the course again. Confirm that your completed items and overall progress are shown.

## Troubleshooting

- **The course is not listed:** ask an instructor to enroll you or check that you are using the correct account.
- **An item is locked:** complete the prerequisite or contact the course instructor.
- **Progress is missing:** reconnect to the network, reopen the item, and allow synchronization to finish.
