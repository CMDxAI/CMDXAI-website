CMDX is a multi-tenant learning management system. Pick the guide for your role.

- [Developers](./developers/overview.md): understand the architecture, build a plugin or a learning item type, call the API, and contribute.
- [Administrators](./administrators/overview.md): install and upgrade CMDX, configure tenants, SSO, roles, backups and feature flags, and migrate from Moodle.
- [Users](./users/overview.md): create and run a course as an instructor, or take a course as a learner.
