CMDX is a multi-tenant learning management system. Pick the guide for your role.

- [Get started](/getting-started/quick-start): run CMDX locally and see a course.
- [Developers](./developers/overview.md): understand the architecture, build a plugin or a learning item type, call the API, and contribute.
- [Administrators](./administrators/overview.md): install and upgrade CMDX, configure tenants, SSO, roles and feature flags, and keep an install running.
- [Users](/users/overview): create and run a course as an instructor, or take a course as a learner.
